# Khojbeen Workspace Design System Rules

## Brand Aesthetic & Guidelines
This codebase strictly adheres to a **Minimal, High-Precision Light Crimson & Obsidian** design system.
- **Theme:** Clean Light Mode (`--surface: #F8FAFC`, `--white: #FFFFFF`).
- **NO Glowing Icons or Neon Highlights:** Maintain sharp 1px borders (`#E2E8F0`), crisp line-art vector icons, and soft subtle elevation shadows (`--shadow-sm`, `--shadow-md`).
- **Typography Pairing:** Font family `'Outfit'`, sans-serif.

## Color Palette Tokens
| Swatch | Hex Code | Role / Usage |
| :--- | :--- | :--- |
| **Primary Crimson** | `#D2122E` | Primary CTA buttons, Active Links, Key Accents |
| **Obsidian Black** | `#0A0F1E` | Headings, High-contrast text, Dark button variant |
| **White** | `#FFFFFF` | Card Containers, Inputs, Top Nav Surface |
| **Light Surface** | `#F8FAFC` | Page Background |
| **Muted Slate** | `#64748B` | Secondary Text, Paragraphs, Subtitles |
| **Border Neutral** | `#E2E8F0` | Structural 1px Borders, Cards, Dividers |
| **Danger Light BG** | `#FEF2F2` | Subtle Tag Fills, Highlight Backgrounds |

## Component Guidelines
1. **Buttons:** Primary (`#D2122E` background, `#FFFFFF` text), Obsidian (`#0A0F1E` background), Secondary (`#F8FAFC` background), Outline (`transparent` background with `#CBD5E1` 1px border).
2. **Cards:** Background `#FFFFFF`, border `1px solid #E2E8F0`, border radius `14px`, shadow `0 1px 3px rgba(0, 0, 0, 0.05)`.
3. **Layout Constants:** Navbar height `73px`, Mobile tab height `60px`.
